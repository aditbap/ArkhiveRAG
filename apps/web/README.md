# `@rag/web` (`web`)

Next.js 16 + Auth.js v5 (Keycloak OIDC) frontend application for the Corporate Adaptive RAG Platform (`port 3000`).

## Features

- Keycloak OIDC authentication via Auth.js (`src/auth.ts`, `src/proxy.ts`)
- Multi-tenant library & folder switcher with RBAC-aware document management (`owner` / `admin` / `member` / `viewer`)
- Adaptive RAG chat interface with retrieval mode selection, SSE streaming, and inline page/section citations
- Guest chat mode when unauthenticated (if enabled on `@rag/api`)

## Required Environment Variables

| Variable | Description |
|---|---|
| `NEXT_PUBLIC_API_URL` | Public URL of `@rag/api` `/api/v1` (inlined at Next.js build time) |
| `AUTH_URL` | Canonical public URL of the web app |
| `AUTH_SECRET` | Random secret for Auth.js session encryption |
| `AUTH_KEYCLOAK_ID` | Keycloak OIDC client ID (`rag-web`) |
| `AUTH_KEYCLOAK_SECRET` | Keycloak client secret (generated by `infra/keycloak/setup-realm.sh`) |
| `AUTH_KEYCLOAK_ISSUER` | Keycloak realm issuer URL |

## Scripts

```bash
pnpm --filter web dev    # Start Next.js dev server
pnpm --filter web build  # Production standalone build
pnpm --filter web start  # Start Next.js server
pnpm --filter web lint   # ESLint (eslint-config-next)
```
